# Nombre del proyecto Trama8583

El nombre elegido es **Trama8583**. Describe una biblioteca Java para construir, interpretar y validar mensajes ISO 8583 mediante perfiles configurables, con un núcleo propio y español para Latinoamérica.

Repositorio: [AngelDeve/trama8583](https://github.com/AngelDeve/trama8583). El artefacto Maven inicial es `trama8583-nucleo` y el POM creado por el mantenedor utiliza `org.gca` como groupId. El registro del repositorio no acredita exclusividad de marca.
